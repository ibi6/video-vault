# 拾影 · Video Vault

在本机集中管理抖音和哔哩哔哩收藏。通过平台自己的页面登录，不需要提交密码或 Cookie 给第三方。

> **当前版本：本机单人使用。** 服务只监听回环地址，尚未实现公网登录、服务器远程扫码登录和无人值守部署。请勿直接绑定公网或添加反向代理对外开放。后续计划见 [服务器版待办](docs/server-roadmap.md)。

## 快速启动

下载或克隆源码后，Windows 可双击项目内的 **`打开拾影.bat`**。

也可以在终端进入源码目录执行：

```bash
cd video-vault
npm ci
npm start
```

打开 **http://127.0.0.1:3210**。首次安装依赖需要联网。保持终端运行；退出用 `Ctrl+C`。

要求 Node.js **22.13+**（建议 Node 24），以及 Chrome 或 Edge。找不到浏览器时：

```bash
npx playwright install chromium
```

服务仅监听 `127.0.0.1`，不是可直接部署到公网的多用户网站。

## 第一次同步

1. 点击某个平台的「连接账号」或进入「账号与同步」。
2. 在弹出的**专用浏览器**里，使用平台自己的二维码/登录界面登录。该窗口与日常浏览器的用户配置隔离，即使你平时已登录，也需要在这里登录一次。
3. 回到拾影点击「开始同步」。抖音必要时在专用窗口进入 **我 → 收藏 → 视频**；若遇到验证码，由你自行完成，然后重试。
4. 在「同步记录」查看实际读取数、新增数和完整性。需要中断时点击「停止本次同步」，最长可能需要等当前网络请求结束。

登录窗口打开不等于登录成功；界面中的「曾验证」只表示过去某次真实读取成功，不能保证会话现在仍有效。每次同步都会重新访问平台检查结果。

## 同步范围与限制（请先阅读）

- **B 站**：用专用浏览器登录态访问账户导航接口，读取自己创建的全部收藏夹并逐页读取视频。不含订阅的他人收藏夹。非视频条目会跳过并在记录中说明。每个文件夹本次最多读取 20,000 条，达到上限显示部分同步。
- **抖音**：打开个人收藏页，只监听 `/aweme/v1/web/aweme/listcollection/` 的收藏响应，通过正常页面滚动加载更多。不会把「喜欢」、推荐流或搜索结果导入。
- **抖音完整性**：只有观察到从 `cursor=0` 连续到 `has_more=0` 的分页链，才会报告完成。未读到首页/末页、分页格式变化、加载停滞、超时或中断时，保留已读内容并报告部分同步或错误。一次滚动任务约两分钟内结束，实际耗时还取决于页面加载。
- **抖音范围**：同步视频收藏列表，不包含音乐及单独收藏夹。抖音网页路由、按钮、验证策略可能变化，因此无法承诺无人值守的稳定全量同步。程序不破解签名，不绕过验证码或平台权限。
- **自动同步**：在设置中逐个平台开启。服务运行期间每 30 分钟尝试一次，可能弹出专用浏览器；电脑休眠或服务关闭时不会运行。不自动并发重复同步同一平台，也不无休止重试。
- **只读归档，不是双向镜像**：不会在平台上新增/取消收藏、点赞或发布内容；原平台取消收藏后，本地旧条目也不会自动删除。同步保留已有标签、已看/稍后看标记以及曾出现过的收藏夹信息。
- **单人片库**：同一平台更换账号后，收藏会合并到现有库。若要完全隔离另一个人的账号，请使用不同 `VAULT_DATA_DIR`。
- **站内播放**：使用 B 站及抖音官方嵌入播放器。作品授权、地区、登录状态、浏览器策略可能造成无法播放；界面始终提供「去原平台播放」。本网站不下载视频、不代理受限视频、不承诺移除水印。
- **收藏时间**：有平台收藏时间时使用它，否则记录首次读取时间；重复同步不会把老视频全变成最新收藏。

## 已实现功能

- SQLite 本地持久化、跨收藏夹去重、增量新增计数
- 标题、作者、标签搜索；来源/收藏夹筛选；时间与标题排序；分页
- 稍后再看、已看标记、自定义标签（最多 12 个，每个 30 字）
- 桌面与手机尺寸的响应式界面，`/` 聚焦搜索，`Esc` 关闭弹窗
- 同步进度、部分结果、错误记录、停止任务、重启后的中断状态恢复
- JSON 导出收藏清单，不包含浏览器会话或登录信息。**清单仍包含你的私人收藏、作者、标签与时间，不应随源码公开。**
- 完整空状态；**正式数据库不会自动填充演示视频**

## 数据与隐私

- `data/vault.sqlite`：收藏、个人标记、同步记录、设置。
- `data/browser-profiles/bilibili/` 与 `data/browser-profiles/douyin/`：隔离的浏览器用户配置，包括登录状态。这些是敏感目录，**不要分享、提交到 Git 或发送给他人**。
- 登录态由浏览器管理，应用不导出 Cookie，不向第三方同步服务发送账号信息。加密和访问保护依赖浏览器与操作系统，**并非独立加密保险箱**，不能抵御同机恶意软件。
- 播放器、视频封面和平台同步仍会直接访问对应平台；“本地存储”不表示完全离线。
- 服务检查 Host、Origin、跨站请求和写操作令牌；静态服务仅公开 `public/`，不会公开 `data/`。没有公网登录/多用户鉴权，勿直接反向代理对外开放。
- 仅导出 JSON 不含登录凭据，但包含个人收藏元数据，分享前仍需自行确认。完整迁移或备份时先停止服务，再备份本项目的 `data/` 目录到你信任的位置。JSON 当前是清单导出，不提供界面导入。
- 清除平台登录状态：停止服务并关闭专用浏览器后，删除对应的 `data/browser-profiles/<平台>/` 目录。下次连接会重新登录，不影响本地收藏。

## 配置

可用环境变量：

- `PORT`：默认 `3210`。Windows CMD 示例：`set PORT=3211`，然后 `npm start`。
- `VAULT_DATA_DIR`：默认项目里的 `data`；可设为绝对路径。
- `VAULT_BROWSER`：指定 Playwright 浏览器通道，例如 `chrome` 或 `msedge`。默认按 Chrome、Edge、Playwright Chromium 的顺序尝试。

## 开发与检查

```bash
npm run dev       # Node watch 模式
npm run check     # 源文件语法检查
npm test          # 单元与 HTTP API 测试
npm run test:ui   # 真实 Chrome 中的 UI 和模拟平台响应测试
npm run release:check  # 检查发布白名单、当前源码及 Git 暂存区的敏感内容
```

`test:ui` 使用临时数据库和网络拦截，不需要登录，不会给真实账号增加收藏。截图在 `artifacts/`，含 `fixture` 的截图仅展示测试数据。该测试验证程序行为，**不能证明当前真实账号在抖音/B 站可全量同步**；真实登录、权限、验证码和作品可播放性仍需在本机手动验收。

### 手动验收

- 两个平台分别登录；用小型真实收藏夹核对标题、条数及新增数。
- 再同步一次确认不会重复新增，标签与观看标记不丢失。
- 抖音确认确实进入收藏而不是喜欢页；比较平台数目和同步完整性状态。
- 同步时关闭专用窗口，检查是否显示失败/部分结果，而非假成功。
- 重启服务后核对收藏和设置；实际打开两平台播放器确认播放或降级链接可用。

## 排错

- **地址打不开**：确认启动终端仍在运行，访问 `http://127.0.0.1:3210` 而不是 HTTPS。
- **端口被占用**：可能已启动过。先打开现有页面，或设置另一个 `PORT`。
- **浏览器打不开**：安装 Chrome/Edge，或运行 `npx playwright install chromium`。退出残留专用窗口后重试。不会使用你平时的浏览器配置来绕过配置锁。
- **B 站未登录 / 风控**：在专用窗口完成登录/验证，等待后重试。
- **抖音无响应 / 部分同步**：确认专用窗口进入「我 → 收藏 → 视频」，完成登录/验证。不能把没有观察到的收藏当作已同步。
- **封面/视频不可用**：源内容可能失效，或平台不允许嵌入，使用原平台链接。

## 上传 GitHub 前

**不要直接压缩整个工作目录，也不要上传 `data/`。** `.gitignore` 仅约束 Git，不会自动清洗手工压缩包。

发布流程见 [源码发布指南](docs/publishing.md)，安全边界见 [SECURITY.md](SECURITY.md)。

```bash
npm run release:check
# 如果目录还不是 Git 仓库，先执行 git init -b main
npm run release:stage  # 只暂存 scripts/release-manifest.json 中列出的允许文件
npm run release:pack  # 从已检查的 Git 暂存树生成 dist/video-vault-source.zip
```

这些脚本不会提交代码、创建远程仓库或推送到 GitHub，也不会删除本地收藏或登录状态。发布包不含数据库、浏览器配置、研究记录、日志、截图、依赖目录或 `.git` 历史。首次公开前请自行决定仓库可见性和许可证；本次整理未替你选择开源许可证。
