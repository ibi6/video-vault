# 服务器版待办（尚未实现）

## 目标

电脑关机后仍能由服务器定时读取收藏，用户通过受保护的网站访问视频库。正常情况后台运行；只有登录过期、验证码或平台限制时需要人工处理。

不承诺永久零人工干预，不绕过验证码、访问控制或平台风控。

## 当前已实现

- 本机个人收藏库、SQLite 持久化、来源筛选、标签与播放器。
- 隔离浏览器窗口登录，B 站收藏夹分页读取和抖音收藏响应监听。
- 服务运行期间可选的 30 分钟定时同步、失败/部分结果与中断记录。
- 回环地址限制和基础跨站写入防护。

这些不能替代公网安全要求。当前监听地址不应该仅改成 `0.0.0.0` 就上线。

## 必须完成后才能公网部署

- [ ] **用户认证**：管理员登录、受保护的服务会话、安全 Cookie、CSRF 防护、登录频率限制及会话吊销。
- [ ] **远程平台授权**：网页可用的扫码/授权入口、过期状态和重新登录流程；不能只在服务器本机弹出一个不可见窗口。
- [ ] **验证挑战处理**：受身份验证保护且短时有效的人工操作通道，不对公网暴露未保护的 VNC、浏览器调试端口或会话文件。
- [ ] **凭据管理**：浏览器配置单独挂载，严格权限；密钥/令牌不进入源码或镜像，备份访问可控。
- [ ] **后台任务**：服务开机启动、独立同步 worker、并发锁、有限重试与退避、超时、重启恢复。
- [ ] **异常通知**：只发送脱敏的登录失效/任务失败提醒，不发送 Cookie、认证 URL 或私人收藏清单。
- [ ] **部署配置**：HTTPS、受信任代理、明确允许的站点 Origin/Host、非 root 运行、资源限制与浏览器依赖。
- [ ] **备份和迁移**：停写一致性或 SQLite 安全备份、恢复演练、数据库迁移版本。
- [ ] **真实环境验收**：用目标服务器实际网络和机房 IP 分别验证 B 站及抖音；风险控制与收藏完整性不能只靠模拟测试推断。

## 平台差异

B 站适合登录有效时进行定时分页读取，但仍可能遇到登录失效、接口变化或风控。

抖音当前通过网页加载收藏数据。服务器要有可运行的浏览器环境，后台模式与机房网络都必须实测；遇到验证码仍需用户处理。若目标环境不稳定，应明确选择继续保留本地同步器或接受人工辅助，不能把部分结果标成全量同步。

## 尚待确认的部署条件

服务器系统/架构、网络地区、内存、域名和 HTTPS、部署方式，以及是否继续只给一位用户使用。这些确定后再添加真正可运行、经过验收的容器或服务配置。本次源码整理不附带未经验证的“公网一键部署”。
